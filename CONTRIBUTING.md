# Contributing to Groupor Backend

Thank you for your interest in contributing!

## Guidelines
1. Fork the repo and clone locally.
2. Ensure Python 3.11+ is installed.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Verify tests and linting before submitting PRs.
5. Provide clear docstrings and typing annotations for all new endpoints and database models.
